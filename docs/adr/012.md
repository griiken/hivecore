# ADR-012 · 2026-04-29 · Use `microsoft/duroxide` for durable orchestrator

**Decision.** `hivecore-orchestrator` wraps `microsoft/duroxide` (MIT, Rust, ~70★, v0.1.27 alpha) for durable execution primitives — function chaining, fan-out/fan-in, durable timers, exactly-once resume on crash. Hivecore adds persona-state semantics and workflow-DAG executor on top.

**Context.** Building journal-replay + saga compensation from scratch is non-trivial and well-understood (Temporal, Durable Task Framework, Restate). duroxide is Microsoft's Rust take on this, embeddable in-process (no external server like Temporal). Vendoring or pinning a specific commit gives us escape hatch if upstream stalls.

**Alternatives considered.** Build from scratch (~30% of P3 scope). Temporal SDK Rust (requires external Temporal cluster, heavier deployment). Restate SDK Rust (similar to Temporal).

**Consequences.** Trades small alpha-stage risk for ~30% scope reduction in Phase 3. Pin to specific version; vendor a snapshot if upstream goes stale.

**Revisit when.** duroxide is unmaintained for >6 months, OR our usage outgrows what duroxide supports.
