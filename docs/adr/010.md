# ADR-010 · 2026-04-29 · `.research/` is reference pointers, not content dumps

**Decision.** External research (papers, blog posts, OSS projects, vendor docs) is captured as 10-line maximum pointer files under `.research/`, with URL + why-it-matters + anchor fact + status + date-checked. Content is never copied; URLs are the canonical source.

**Context.** Dead docs are worse than no docs. Copying long external content into the repo creates a maintenance burden, drifts from source, and clutters review. A lean pointer index lets contributors find sources fast without bloating the repo.

**Alternatives considered.**
- **Full-text capture** — preserves against link rot but rots faster; nobody reads it.
- **External Notion/Confluence research wiki** — lives outside the repo, contributors miss it.
- **No research dir** — loses traceability of why we made decisions.

**Consequences.** Maintenance is light: quarterly URL liveness check, anchor fact preserves the takeaway if URL dies. Contributors must follow URLs to read source. Trade: speed > completeness.

**Revisit when.** A specific research source dies + matters enough to merit re-creation in-repo.
