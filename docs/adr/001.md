# ADR-001 · 2026-04-29 · Project bootstrapped via project-ignition

**Decision.** Hivecore was scaffolded with the `project-ignition` skill (full mode), producing the standard agent-coding + OSS hygiene tree.

**Context.** Starting a new OSS project. Manual scaffolding is slow and inconsistent. The ignition skill encodes the team's standard layout (CLAUDE.md, AGENTS.md, docs/, .claude/, dual licensing, OSS hygiene files) in one pass.

**Alternatives considered.**
- Manual scaffolding from a template repo.
- Fork an existing project structure.
- Use a different generator (cargo-generate, create-next-app standalone).

**Consequences.** Consistent baseline matching prior projects, agent-ready from day one, dual licensing precedent set. Cost: skill output is opinionated; deviations require explicit ADRs.

**Revisit when.** Scaffold conventions diverge from team standards or new agent platforms emerge needing different files.
