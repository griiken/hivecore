# ADR-003 · 2026-04-29 · Target agents: Claude Code + Codex (cross-agent compatible)

**Decision.** Hivecore's `.claude/` dogfood and `AGENTS.md` cross-agent rules target Claude Code + Codex as primary, with the AGENTS.md being self-contained so other agents (Cursor, Continue, Cline, Windsurf, Aider, OpenCode) can also work in the repo.

**Context.** The author uses Claude Code primarily. Codex is the second-most-likely agent for this project. Cross-agent compatibility costs little (AGENTS.md self-contained instead of @import-only) and broadens contributor accessibility.

**Alternatives considered.**
- Claude-Code-only — narrows contributor base.
- Every-agent-equally — overhead in maintaining N agent-specific configs.

**Consequences.** Two configs to maintain (CLAUDE.md with @imports + AGENTS.md self-contained), but contributor base is broad.

**Revisit when.** A specific agent's tooling needs (e.g., Cursor's `cursorrules`) becomes blocking for adoption.
